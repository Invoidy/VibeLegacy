Beginner's Guide

Just follow the steps in order — you don't need to know anything in advance.

1

Download and install VibeLegacy

Download the installer using the link below and run it.

VibeLegacy-Setup-0.1.1.exe
After installation, you can run the program with the vibelegacy command from any folder in cmd.
2

First launch

Open cmd and type:

> vibelegacy

You will see this message:

Welcome to VibeLegacy!

Before you start, configure the .CONFIG_ME file with your API settings.

You can view all available commands with /help.

Main commands:

* /add <file> — attach a file to the conversation
* /drop <file> — remove an attached file
* /clear — clear the message history

Once configured, just describe what you want to build or change, and VibeLegacy will handle the code changes.

Have fun vibing — with control.

The program will also open the folder containing the .CONFIG_ME file in Explorer — that is the file you need to find and fill in.

3

Get an API key

You need an access key for the AI model. Choose one of two options:

OpenRouter
  1. Go to openrouter.ai and sign up
  2. Top up your balance
  3. Go to the Keys section → «Create Key» → copy the key
Polza.ai (for Russia)
  1. Go to polza.ai and sign up
  2. Top up your balance with a Russian bank card or via SBP — no VPN needed
  3. Dashboard → API Keys → create a key and copy it
4

Fill in .CONFIG_ME

Open .CONFIG_ME in Notepad (right-click → "Open with" → "Notepad") and paste one of the options below in place of all its contents. The key in the example is just a format sample — replace it with your own real key.

If your key is from OpenRouter:

BASE_URL=https://openrouter.ai/api/v1
API_KEY=sk-or-v1-xxxxxxxxxxxxxxxxxxxxxxxxxxxx
MODEL=anthropic/claude-haiku-5.5
REASONING=high

If your key is from Polza.ai:

BASE_URL=https://polza.ai/api/v1
API_KEY=pza_xxxxxxxxxxxxxxxxxxxxxxxxxxxx
MODEL=anthropic/claude-haiku-5.5
REASONING=high

Save the file (Ctrl+S) and close Notepad.

5

Run the program in your project folder

This time, you need to open cmd in the project folder — the one containing the code you want to change. There are several ways to do this:

Using the Explorer address bar

Open your project folder in Explorer, click the address bar (where the folder path is), delete what's there, type cmd and press Enter — cmd will open right in this folder.

Using the cd command in an already open cmd

If cmd is already open somewhere else, switch to the project folder with the cd and the folder path:

> cd C:\Users\Имя\my_project
Using the IDE terminal

If you open the project in VS Code or PyCharm, they have a built-in terminal (View → Terminal in VS Code, the Terminal tab at the bottom in PyCharm), which is already open in the project folder. You can type the command right there.

Once cmd is open in the project folder, run:

> vibelegacy

The same welcome message from step 2 will appear — but now that the config is filled in, the program is ready and waiting for your command.

6

Add your project files

You are already inside VibeLegacy, running in the project folder. Use /add to add the files you want to work with — the model will see them and can only change them. Paths are relative to the project folder, so a file in a subfolder is added together with the subfolder's name. For example, with this structure:

📁 my_project
  ├── main.py
  ├── utils.py
  └── 📁 src
      └── helpers.py
> /add main.py src/helpers.py

You can list several files at once, separated by spaces. To remove a file, use /drop; to remove all files, use /dropall.

7

Describe what you need

Describe the task in plain words and press Enter. To start a new line, press Shift+Enter.

> добавь в функцию main() обработку ошибки деления на ноль

The model will make the changes directly to the files on disk — you don't need to edit anything by hand. To stop generation, press Ctrl+C.

8

Changed your mind? Undo the changes

Don't like the result? Type /undo and the file will go back to how it was before the AI edit. If you need the changes again, /redo will bring them back, including your manual edits.

> /undo
Changes discarded. Use /redo to restore them.
If you manually edited the file after an AI edit, the program will warn you before /undo or /redo — so you don't accidentally overwrite your changes.
9

Done!

The whole workflow: /add → describe the task → check the result → if needed, /undo or /redo. Repeat for the next task. To exit, press CTRL+C.

Cheat sheet

All commands in one place

Command What it does
/help Show the list of all commands
/add <file> Add file(s) to the context — several can be listed, separated by spaces
/drop <file> Remove file(s) from the context
/dropall Remove all files from the context at once
/clear Clear the conversation history with the model
/undo Undo the last AI edit (step by step)
/redo Redo an undone AI edit (step by step)
/config Open the folder with the .CONFIG_ME settings file
/exit Exit VibeLegacy

File paths in /add are relative to the folder the program was launched from.

Something not working?

Check that there are no extra spaces around the key in .CONFIG_ME and that your provider balance has funds. If that doesn't help, describe the problem in Issues on GitHub.
