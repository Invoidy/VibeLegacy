VibeLegacy

"Вайб под контролем."

Консольный ИИ-ассистент для программирования, который редактирует ваши файлы с помощью компактных SEARCH/REPLACE-блоков. Вы решаете, какой контекст видит модель, а каждую правку ИИ из текущей сессии можно пошагово отменить и вернуть командами /undo и /redo.

Запускается за долю секунды прямо из консоли в папке вашего проекта. Минимальное потребление памяти, никаких фоновых процессов.

Экономия токенов

Модель присылает точечные SEARCH/REPLACE-блоки вместо переписывания всего файла, что экономит токены API.

Минимальный расход токенов на каждую правку

Полный контроль и /undo

Вы сами выбираете, к каким файлам ИИ имеет доступ, с помощью /add. Команды /undo и /redo шаг за шагом перемещаются назад и вперёд по правкам ИИ в текущей сессии.

Пошаговая отмена и повтор (только текущая сессия)

Настройка приложения

Настройка .CONFIG_ME

При самом первом запуске vibelegacy.exe автоматически создаёт шаблон файла .CONFIG_ME рядом с исполняемым файлом, открывает папку в проводнике и завершает работу.

1
Укажите свои ключи Откройте .CONFIG_ME в любом текстовом редакторе и укажите свой API_KEY.
2
Запустите снова Сохраните файл и снова запустите vibelegacy.exe. Приложение готово к работе!
3
Команда /config В любой момент введите /config, чтобы быстро открыть папку с файлом конфигурации.
Пример файла .CONFIG_ME 
BASE_URL=https://openrouter.ai/api/v1
API_KEY=your_api_key_here
MODEL=anthropic/claude-haiku-5.5
REASONING=high
BASE_URL: URL любого API, совместимого с OpenAI (по умолчанию OpenRouter).
API_KEY: Ваш персональный API-ключ от провайдера.
MODEL: Идентификатор модели (например, anthropic/claude-haiku-5.5 или deepseek/deepseek-v4.1-flash-1017).
REASONING: Уровень рассуждений (none, low, medium, high, xhigh, max) или оставьте пустым.

Разработка

Сборка .exe с помощью Nuitka

Вы можете самостоятельно собрать VibeLegacy в автономный исполняемый файл для Windows с помощью компилятора Nuitka.

Команды сборки для PowerShell / CMD 
# 1. Клонируйте репозиторий
git clone https://github.com/Invoidy/VibeLegacy.git
cd VibeLegacy

# 2. Создайте и активируйте виртуальное окружение Python 3.14+
python -m venv venv
venv\Scripts\activate

# 3. Установите зависимости
pip install -r requirements.txt
pip install nuitka

# 4. Соберите исполняемый файл .exe
python -m nuitka --standalone --remove-output --output-dir=dist --output-filename=vibelegacy.exe --windows-icon-from-ico=logo.ico --include-package-data=binaryornot --include-data-files=first_start=first_start main.py

Результат сборки появится в dist/main.dist/vibelegacy.exe.
