Гайд для начинающих

Просто повторяй шаги по порядку — ничего не нужно знать заранее.

1

Скачай и установи VibeLegacy

Скачай установщик по ссылке ниже и запусти его.

VibeLegacy-Setup-0.2.exe
После установки программу можно запускать командой vibelegacy из любой папки через cmd.
2

Первый запуск

Открой cmd и введи:

> vibelegacy

Появится такое сообщение:

Welcome to VibeLegacy!

Before you start, configure the .CONFIG_ME file with your API settings.

You can view all available commands with /help.

Main commands:

* /add <file> — attach a file to the conversation
* /drop <file> — remove an attached file
* /clear — clear the message history

Once configured, just describe what you want to build or change, and VibeLegacy will handle the code changes.

Have fun vibing — with control.

Программа заодно сама откроет в проводнике папку с файлом .CONFIG_ME — его и нужно найти и заполнить.

3

Получи API-ключ

Нужен ключ доступа к нейросети. Выбери один из двух вариантов:

OpenRouter
  1. Зайди на openrouter.ai и зарегистрируйся
  2. Пополни баланс
  3. Раздел Keys → «Create Key» → скопируй ключ
Polza.ai (для России)
  1. Зайди на polza.ai и зарегистрируйся
  2. Пополни баланс картой РФ или через СБП — без VPN
  3. Dashboard → API Keys → создай ключ и скопируй его
4

Заполни .CONFIG_ME

Открой .CONFIG_ME блокнотом (правый клик → «Открыть с помощью» → «Блокнот») и вставь один из вариантов ниже вместо всего содержимого. Ключ в примере — просто образец формата, замени его на свой настоящий.

Если ключ с OpenRouter:

BASE_URL=https://openrouter.ai/api/v1
API_KEY=sk-or-v1-xxxxxxxxxxxxxxxxxxxxxxxxxxxx
MODEL=anthropic/claude-haiku-5.5
REASONING=high

Если ключ с Polza.ai:

BASE_URL=https://polza.ai/api/v1
API_KEY=pza_xxxxxxxxxxxxxxxxxxxxxxxxxxxx
MODEL=anthropic/claude-haiku-5.5
REASONING=high

Сохрани файл (Ctrl+S) и закрой блокнот.

5

Запусти программу в папке проекта

На этот раз cmd нужно открыть именно в папке проекта — той, где лежит код, который нужно поменять. Есть несколько способов:

Через адресную строку проводника

Открой папку проекта в проводнике, кликни в адресную строку (где путь к папке), сотри что там есть, набери cmd и нажми Enter — cmd откроется сразу в этой папке.

Командой cd в уже открытом cmd

Если cmd уже открыт где-то ещё — перейди в папку проекта командой cd и путём к ней:

> cd C:\Users\Имя\my_project
Через терминал в IDE

Если открываешь проект в VS Code или PyCharm — у них есть встроенный терминал (View → Terminal в VS Code, вкладка Terminal внизу в PyCharm), который уже открыт в папке проекта. Команду можно вводить прямо там.

Когда cmd открыт в папке проекта, запусти:

> vibelegacy

Появится то же приветственное сообщение, что и в шаге 2 — но теперь, раз конфиг заполнен, программа готова к работе и ждёт команду.

6

Добавь файлы своего проекта

Ты уже внутри VibeLegacy, запущенного в папке проекта. Командой /add добавь файлы, с которыми нужно работать — модель будет видеть и сможет менять только их. Пути указываются относительно папки проекта, так что файл из подпапки добавляется вместе с её названием. Например, при такой структуре:

📁 my_project
  ├── main.py
  ├── utils.py
  └── 📁 src
      └── helpers.py
> /add main.py src/helpers.py

Можно перечислить сразу несколько файлов через пробел. Убрать файл — /drop, убрать все — /dropall.

7

Напиши, что нужно сделать

Опиши задачу обычными словами и нажми Enter. Для переноса строки — Shift+Enter.

> добавь в функцию main() обработку ошибки деления на ноль

Модель сама внесёт изменения прямо в файлы на диске — ничего руками редактировать не нужно. Остановить генерацию — Ctrl+C.

8

Передумал? Отмени изменения

Не понравился результат — введи /undo, файл вернётся к виду до правки ИИ. Снова нужны эти изменения — /redo вернёт их обратно, включая ручные правки.

> /undo
Changes discarded. Use /redo to restore them.
Если ты сам вручную поправил файл после правки ИИ, программа предупредит об этом перед /undo или /redo — чтобы не затереть твои правки случайно.
9

Готово!

Весь цикл работы: /add → описал задачу → проверил результат → при необходимости /undo или /redo. Повторяй для следующей задачи. Выйти — CTRL+C.

Шпаргалка

Все команды в одном месте

Команда Что делает
/help Показать список всех команд
/add <файл> Добавить файл(ы) в контекст — можно несколько через пробел
/drop <файл> Убрать файл(ы) из контекста
/dropall Убрать все файлы из контекста разом
/clear Очистить историю переписки с моделью
/undo Отменить последнюю правку ИИ (по шагам)
/redo Вернуть отменённую правку ИИ (по шагам)
/config Открыть папку с файлом настроек .CONFIG_ME
/exit Выйти из VibeLegacy

Пути к файлам в /add указываются относительно той папки, откуда запущена программа.

Что-то не работает?

Проверь, что в .CONFIG_ME нет лишних пробелов вокруг ключа и что на балансе провайдера есть средства. Если не помогло — опиши проблему в Issues на GitHub.
