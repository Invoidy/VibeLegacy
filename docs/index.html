Application setup

Configuring .CONFIG_ME

On the very first launch, vibelegacy.exe automatically creates a template file named .CONFIG_ME next to the executable, opens the folder in Explorer, and exits.

1
Fill in your keys Open .CONFIG_ME in any text editor and set your API_KEY.
2
Run it again Save the file and run vibelegacy.exe again. The app is ready to go!
3
The /config command At any time, type /config to quickly open the folder containing the config file.
Example .CONFIG_ME file 
BASE_URL=https://openrouter.ai/api/v1
API_KEY=your_api_key_here
MODEL=openai/gpt-6.1-sol
REASONING=high
BASE_URL: URL of any OpenAI-compatible API (OpenRouter by default).
API_KEY: Your personal API key from the provider.
MODEL: Model identifier (e.g. openai/gpt-6.1-sol or deepseek/deepseek-v4.1-flash-1017).
REASONING: Reasoning level (none, low, medium, high, xhigh, max) or leave empty.

Development

Building the .exe with Nuitka

You can compile VibeLegacy yourself into a standalone Windows executable using the Nuitka compiler.

PowerShell / CMD build commands 
# 1. Clone the repository
git clone https://github.com/Invoidy/VibeLegacy.git
cd VibeLegacy

# 2. Create and activate a Python 3.14+ virtual environment
python -m venv venv
venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt
pip install nuitka

# 4. Build the .exe executable
python -m nuitka --standalone --remove-output --output-dir=dist --output-filename=vibelegacy.exe --windows-icon-from-ico=logo.ico --include-package-data=binaryornot --include-data-files=first_start=first_start main.py

The build output will appear in dist/main.dist/vibelegacy.exe.
